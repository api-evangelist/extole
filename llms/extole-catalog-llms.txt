# Extole

> Extole is an enterprise referral, advocacy, and loyalty marketing platform. Its API lets brands create and manage referral programs, generate share links, issue and reconcile rewards, build audiences, render campaign content zones, and subscribe to events via webhooks.

## APIs
- [Integration API - Consumer to Extole](https://developers.extole.com/): consumer/advocate-facing share, referral, and profile operations. Host: https://{brand}.extole.io
- [Integration API - Server to Extole](https://developers.extole.com/): server-side rewards, persons, events, files. Host: https://api.extole.io
- [Management API](https://developers.extole.com/): audiences, campaigns, webhooks, reports, settings. Host: https://api.extole.io
- [Management Expert API](https://developers.extole.com/): advanced campaign, component, and reporting controls. Host: https://api.extole.io

## Auth
Token-based: send an Extole access token via the Authorization header (Bearer), the extole_token cookie, or the access_token query parameter.
